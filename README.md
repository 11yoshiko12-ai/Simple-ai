# Simple-ai
This a ai called verity he is like the ai in minecraft but it is a app
SETUP
note: This will only work on on windows

1. Find the verity_companion-copy.py in my Github page and download it
2. open the terminal on your computer and copy the following stuff one by one and paste it to the terminal,
pip install pyttsx3
pip install qroq
pip install pillow
pip install requests
If it tells you that there is a new pip to be downloaded please download
Right click on the verity_companion-copy find edit in notepad and click on it
Find line 10 or find GROQ_API_KEY and put a api key from this web https://console.groq.com/keys
where it says Put in your api keys here delete the text not the "" and put in your api key
Click file then click save in notepad
Find verity_companion-copy in downloads and double click it to start the ai.
